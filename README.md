# Netflix Homepage UI Clone

A modern and responsive Netflix homepage UI clone built using HTML, CSS, and JavaScript.

## Features
- Responsive Netflix-inspired UI
- Hero banner section
- Modern navigation bar
- Interactive buttons and hover effects
- Movie poster layout
- Mobile-friendly design

## Technologies Used
- HTML5
- CSS3
- JavaScript
